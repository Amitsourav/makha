# स्वsnacks — Loop 3: Packaging System (v2, post-critique)

Format ladder: Pouch (trial/repeat) → Glass Jar (home ritual) → Ceramic
Reserve Jar (collector/gift) → Gift Box (occasion). Every format shares the
same label hierarchy so the shelf reads as one house.

## 1. Stand-up pouch — "The Weekly Tin's understudy" (80g / 200g)
- **Front:** soft-touch matte espresso film (NOT kraft — kraft is the organic
  cliché). Cream label panel, top-centre grading seal (स्व monogram),
  MAKHANA + flavor name in Rozha One, grade line "6-SUTA LAWA · 24MM+",
  roast-week stamp (sindoor ink, actually stamped at the roastery), net wt.
  Flavor color band across the bottom 18mm — the "library spine."
- **Back:** The Standard in 60 words; ingredient list set LARGE ("read in one
  breath" is the design idea); nutrition table in tabular numerals; GI-tag
  logo + FSSAI; QR → "meet your pond" film. No window — premium packs don't
  beg; the glass jar does the showing.
- Resealable zipper, bottom gusset prints the pond name.

## 2. Glass jar system (150g)
Clear flint glass — **the seeds are the proof of grade**, so here the product
is the front. Tall cream wrap label at 55% height, same hierarchy; espresso
powder-coated metal lid, seal embossed. Under-lid message: "Popped by hand.
Opened the same way."

## 3. Premium (Reserve) jar system (200g)
Matte espresso ceramic canister, copper hot-foil seal, ash-wood airtight lid.
Named editions ("Reserve: Pond No. 4, Darbhanga"). Refill pouches make it a
permanent kitchen object — sustainability as luxury logic, Aesop-style.

## 4. Gift box — "The Tasting Library"
Rigid board, cream letterpress exterior, espresso interior, six tins spine-out
like books, sindoor ribbon pull, provenance card in Rozha One. Diwali edition:
espresso exterior, copper foil rangoli-geometry, no cliché diyas.

## Label hierarchy (all formats, 5 fixed levels)
1. Seal/monogram (identity) · 2. MAKHANA (category, largest Latin word)
3. Flavor name (Didone, two lines max) · 4. Grade + roast week (copper/sindoor)
5. Net wt / legal (smallest, never cramped)

Typography hierarchy: Rozha One for 2–3; Hanken Grotesk caps for 4–5;
letterspacing increases as size decreases.

## Materials & print
- Pouch: matte BOPP soft-touch, 5-color + spot matte varnish on seal.
- Labels: uncoated FSC cotton-blend stock, letterpress or deboss seal,
  copper hot-foil (Kurz Luxor-alike), sindoor as spot color (≈Pantone 173C).
- Board: 2mm rigid, cream uncoated wrap, copper foil + blind deboss.
- Ceramic: matte glaze, fired copper decal.

## Shelf impact strategy
1. **Espresso block** in a category of white/green/kraft = instant contrast.
2. **स्व as beacon:** the Devanagari monogram is legible at 3 metres and
   belongs to no one else on the shelf.
3. **Library spine effect:** constant cream label + flavor band bottom means
   a facing row reads as a collected set, pushing multi-SKU purchase.
4. Constant seal position = instant brand recognition across formats.

## Critique log (v1 → v2), benchmarked vs global premium
Benchmarks: Diaspora Co. (Indian-global provenance), Brightland (label
discipline), Torres (black-pack shelf contrast), Subko (bilingual craft),
Casa Bosques (restraint).
- *"Window on pouch?"* → killed; windows read mass. Glass jar does the showing.
- *"Six flavor colors could go candy-aisle"* → all hues desaturated-rich;
  saturation capped; tested as a shelf row, not singly.
- *"Ceramic jar gimmick risk"* → tied to refill economy; it earns its place.
- *"Diwali edition cliché risk"* → no diyas, no marigold; geometry + copper.
- *"Shelf standout score"*: v1 ~7/10 (seal too small at distance) → v2: seal
  enlarged 1.4×, MAKHANA weight increased; est. 9/10 — espresso block + alien
  script + library row is a three-signal standout no category peer has.
